
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：部门名 / 院系名 / 活动名 / 项目名 / 人名。
2. 原标题已经清楚点出主体的：保持原意，不要为改写而改写。
3. 原标题只是编号 / 口号 / 没信息量的 teaser（如 "第 74 期"、"重磅"、"与你有关"）时，结合【来源】和正文把主体补进标题。例：原标题 "余瑞璜大讲堂（七十四）" + 正文主题 → "余瑞璜大讲堂第七十四期讲材料与 AI 逆向设计"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体部门或院系时，用上位词（如"学校""相关院系"）兜底，绝不凭"常识"编一个具体部门 / 院系 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：通知 / 预告 / 解读 / 综述 / 表彰这类标题，中文标题必须保留这个类型；不能因为正文谈到一项已经发布的安排或成果，就改写成“发布 / 推出 / 立项”。只有原标题明确宣布了发布、通知、立项或表彰，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的部门、院系、活动名。
   例：原标题 "关于 2026 年秋季学期选课的通知" → 保持通知类型，可补主体为 "教务处发布 2026 年秋季学期选课通知"，但不能写成 "教务处调整选课制度"。
   例：一篇回顾某场讲座的综述 → 标题写讲座内容与讲者，不能写成 "某学院举办讲座" 以外的发布口径。
